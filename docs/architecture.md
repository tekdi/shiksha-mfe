# Architecture: AI Engine Integration

## Overview
The `ai-engine` is a Python-based FastAPI backend service responsible for processing educational content (such as PDFs) and extracting structured data for the Shiksha MFE platform.

## Integration Points

### Content MFE
The Content MFE acts as the primary interface for content creation and management.
- **Upload**: When a user uploads a PDF document via the Content MFE, it will make a `POST` request to the `/ingest` endpoint of the `ai-engine`.
- **Processing**: The `ai-engine` processes the document, extracting headers, body text, images, metadata, key takeaways, glossary terms, and a generated narration script.
- **Response**: The structured JSON response is returned to the Content MFE, where the user can review and edit the parsed content before saving it to the main application database.

### Teacher App
The Teacher App consumes the structured content generated by the AI Engine.
- **Content Delivery**: Teachers can use the generated narration script and key takeaways to plan lessons or deliver content directly to learners.
- **Glossary Access**: The extracted glossary provides quick reference definitions for domain-specific terminology found in the uploaded documents.

## Deployment
The `ai-engine` is containerized and can be run independently or alongside other services using `docker-compose.ai.yml`. It runs on port `8000` by default.

## Sample Usage
To test the ingestion endpoint with a local PDF file, you can use `curl`:
```bash
curl -X POST "http://localhost:8000/ingest" \
     -H "accept: application/json" \
     -H "Content-Type: multipart/form-data" \
     -F "file=@sample.pdf"
```
