- [ ] Image extraction and metadata preservation
- [ ] Table parsing and conversion

### Acceptance Criteria
- [x] PDF and PPT files parsed into structured JSON with headers, body

- [ ] Processing time: ≤ 30 seconds for a 50-page document

### Acceptance Criteria
- [x] MCQ, Match-the-Pair, Fill-in-the-Blanks generated strictly from source material
- [x] All question types packaged as valid H5P Question Set and SCORM 1.2 packages
- [ ] SCORM packages import successfully into Moodle 4.x and Open edX
- [ ] LaTeX STEM questions render correctly via MathJax
- [ ] Question quality score ≥ 4/5 (semantic relevance, clarity, variety)

- Enhanced explanations with content takeaways

**Blockers:**
